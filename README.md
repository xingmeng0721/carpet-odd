# Carpet Odd

[![License](https://img.shields.io/github/license/liuyuexiaoyu1/Carpet-Igny-Addition)](https://choosealicense.com/licenses/lgpl-3.0/)

## 简介

Carpet Odd 是一款基于 **Fabric** 平台 **Carpet** 模组开发的附属扩展。

本模组提供了一系列面向建筑玩家与原版生存玩家的实用功能，在尽可能保持原版体验的前提下，提升游戏的便利性与可玩性。

---

## 功能

### 1. 假人纯盒投掷（自动降落）

允许假人自动投掷背包中的**纯潜影盒**（仅包含同一种物品的潜影盒）。

**触发方式**

- 使用命令：
  ```text
  /player <name> autodrop
  ```
- 玩家手持仙人掌，左键点击假人。

---

### 2. 骨粉催熟孢子花

使原版不可再生的孢子花能够实现自动化繁殖。

**效果**

- 对已放置的孢子花使用骨粉。
- 会在附近符合条件的天花板方块上随机生成新的孢子花。

---

### 3. 火把花掉落种子

提升火把花的繁育收益。

**效果**

- 破坏完全成熟的火把花时：
  - 掉落火把花本体；
  - 额外掉落 **1～3 个火把花种子**。

---

### 4. 潜行右键加速铜氧化

为建筑玩家提供更便捷的铜块氧化方式。

**效果**

- 手持斧头并按住潜行（Shift）。
- 右键点击未完全氧化的铜方块。
- 消耗斧头 **1 点耐久**。
- 铜块立即进入下一阶段氧化。

**说明**

- 与原版斧头除锈功能相反。
- 保留原版刮铜音效。
- 对已上蜡的铜块无效。
