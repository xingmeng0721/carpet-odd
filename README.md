## 简介

Carpet Odd 是一款基于 **Fabric** 平台 **Carpet** 模组开发的附属扩展。

本模组提供了一系列面向建筑玩家与原版生存玩家的实用功能，在尽可能保持原版体验的前提下，提升游戏的便利性与可玩性。
