## 地毯奇怪扩展
odd是一款基于 Fabric 平台 Carpet模组 的附属扩展。 本模组添加了一些实用且面向建筑玩家的辅助功能，旨在提升原版生存的便利性与可玩性。
📦 1. 假人纯盒投掷 (自动降落)
功能描述：启用后，可以命令假人自动扔出其背包中的“纯盒”（即内部只装有单一类型物品的潜影盒）。
触发方式：
指令触发：使用命令 /player <name> autodrop
快捷触发：玩家手持仙人掌，左键点击假人即可快速触发
🌸 2. 骨粉催熟孢子花
让原版中不可再生的孢子花变得可实现自动化农场繁育。
功能描述：对已放置的孢子花使用骨粉，将会在其附近的有效天花板方块上随机生成新的孢子花。
🔥 3. 火把花掉落种子 
优化了火把花的种植收益，让繁育这种美丽的植物不再困难。
功能描述：打破完全长成的火把花时，除了掉落本身，还会额外掉落 1 到 3 个 火把花种子。
🪓 4. 斧头潜行右键氧化铜 (斧氧化铜)
建筑党的福音！ 打破原版只能除锈的限制，现在你可以手动加速铜块的氧化过程。
功能描述：玩家手持斧头并按住潜行（Shift）右键点击未完全氧化的铜方块时，会消耗斧头 1 点耐久，并强制使其进入下一个氧化阶段。
注意：此操作与原版除锈行为完全相反，且保留了原版的刮铜音效反馈； 对涂过蜜脾（上蜡）的铜块无效。
